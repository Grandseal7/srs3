Математическая модель

Тепловой баланс

Cₚ · m · dT/dt = Pₕ − Qₗ

Cₚ — удельная теплоёмкость смеси (≈1800 Дж/(кг·°C)), m — масса материала, T — температура, Pₕ — тепловая мощность (в основном трение мешалки), Qₗ — отвод тепла. Принимаем Qₗ = k·(T − Tₒₖᵣ), где k — коэффициент теплоотдачи рубашки охлаждения, Tₒₖᵣ = 20 °C. Смесь греется, пока отвод тепла не сравняется с подводом.

Модель вязкости μ = f(T, n, t, C)

μ = k₀ · e^(a·C) · e^(−b·T) · (n/n₀)^(−c) · (0.6 + 0.4·e^(−t/τ))

Физический смысл

  • Рост C: вязкость растёт (больше твёрдой фазы).
  • Рост T: вязкость падает (жидкость становится подвижнее).
  • Рост n: вязкость снижается (разрушается структура, псевдопластичность).
  • Рост t: пигмент диспергируется, вязкость снижается до плато с постоянной τ.

Какие опытные данные нужны

  • Вязкость при разных T, n, C (вискозиметр).
  • Зависимость μ от времени диспергирования.
  • Масса, теплоёмкость и мощность мешалки.
  • Из них подбираются k₀, a, b, c, τ.

Коэффициенты в примере подобраны для учёбы (a = 0.075, b = 0.022, c = 0.25, τ = 35 мин). В реальной работе их определяют по опытным данным.
